# 🌌 AstroLens

AstroLens es una aplicación web interactiva diseñada para explorar el cielo nocturno. Permite a los usuarios identificar estrellas y constelaciones en tiempo real utilizando la cámara de su dispositivo, o analizando fotografías claras del cielo estrellado que el usuario suba a la plataforma.

## ✨ Características Principales
* **Identificación Fotográfica:** Sube una foto del cielo y descubre qué constelaciones se ocultan en ella.
* **Modo Cámara:** Exploración en tiempo real utilizando la cámara del dispositivo.
* **Reconocimiento Preciso:** Integración con IA generativa para el análisis de patrones estelares y datos astronómicos.
* **Interfaz Intuitiva:** Diseño responsivo y fácil de usar desde cualquier dispositivo móvil o de escritorio.

## 🛠️ Tecnologías Utilizadas
* **Frontend:** HTML5, CSS3, JavaScript
* **Inteligencia Artificial:** Google Gemini API (Modelo 1.5 Flash)
* **Despliegue:** [Ej. GitHub Pages / Vercel / Netlify]
